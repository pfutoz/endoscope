医用画像モダリティ 撮影オーダー連携 開発計画（全館統合版）

1. 概要とプロジェクトの目的

自作PHP予約システムおよび院内データベースから得られる医療情報を基に、各撮影・検査機器へDICOM Modality Worklist (MWL) を介して撮影オーダーを自動配信する仕組みを構築します。

目指す効果：
  • 検査時の患者番号の取り違え防止
  • 患者情報のプロセッサ等への手入力削減
  • オーダー入力ミスの削減
基本方針： プロセッサ等の各機器は直接JSONを読めないため、Python（pydicom / pynetdicom）を用いた軽量な共通DICOM MWLサーバーを中継役（ブリッジ）として常駐させます。

2. 対象機器・モダリティの拡張

内視鏡だけでなく、標準規格（DICOM MWL）に対応したすべての医用画像モダリティへ展開可能です。

モダリティ種類 対象メーカー・機種例 DICOM Modality
内視鏡 富士フイルム (ELUXEO / LASEREO)
オリンパス (290シリーズ等)		 ES (Endoscopy)
超音波 (US) 各社エコー装置 US (Ultrasound)
X線・レントゲン (CR/DR) 各社X線撮影装置 CR または DX

3. 全体システムアーキテクチャ

[ 院内電子カルテ / データベース ]
            │ (情報取得)
            ▼
[ 自作PHPシステム ] ──(JSON出力)──> [ Python MWL中継サーバー ] ──(DICOM通信)──> [ 各種モダリティ機器 ]
                                    (常駐 / C-FIND応答)                         ・内視鏡 (富士/オリンパス)
                                                                                ・超音波 (US)
                                                                                ・X線 (CR/DX)

ステップ③：Python MWLサーバー実装 (`mwl_server.py`)

import json
import os
from pydicom.dataset import Dataset
from pynetdicom import AE, evt
from pynetdicom.sop_class import ModalityWorklistInformationFind

JSON_FILE_PATH = "C:/inetpub/wwwroot/htdocs/data/orders.json"

def load_orders():
    if not os.path.exists(JSON_FILE_PATH):
        return []
    try:
        with open(JSON_FILE_PATH, "r", encoding="utf-8") as f:
            return json.load(f)
    except Exception:
        return []

def handle_find(event):
    req = event.identifier
    orders = load_orders()
    
    for order in orders:
        ds = Dataset()
        ds.PatientID = str(order.get("patient_id", ""))
        ds.PatientName = str(order.get("patient_name_kanji", ""))
        ds.PatientBirthDate = str(order.get("birth_date", ""))
        ds.PatientSex = str(order.get("sex", "O"))
        ds.AccessionNumber = str(order.get("accession_number", ""))
        
        ds.ScheduledProcedureStepSequence = []
        sps = Dataset()
        sps.ScheduledProcedureStepStartDate = str(order.get("exam_date", ""))
        sps.Modality = str(order.get("modality", "ES"))
        ds.ScheduledProcedureStepSequence.append(sps)

        ds.SpecificCharacterSetRepertoire = 'ISO_IR 100'
        yield (0xFF00, ds)

def run_server():
    ae = AE(ae_title=b'MODALITY_MWL_SRV')
    ae.add_supported_context(ModalityWorklistInformationFind)
    port = 11112
    print(f"共通 DICOM MWL サーバー起動中... ポート: {port}")
    handlers = [(evt.EVT_C_FIND, handle_find)]
    ae.start_server(('0.0.0.0', port), evt_handlers=handlers, block=True)

if __name__ == "__main__":
    run_server()
