2. ツールバーUI全面刷新（トグルボタン化・ツライチ統一）

従来、月間カレンダー（month_schedule.php）、予約マトリクス（month_matrix_v2.php）、デイリーノート（schedule_note.php）の各画面では、検査枠の絞り込みや空き枠表示にブラウザ標準のチェックボックスが混在し、ボタンの高さが不揃いで視覚的ノイズとなっていました。

  • 不要絵文字（🎯）の撤去: 視覚的ノイズとなっていた🎯アイコンを排除し、医療現場にふさわしい落ち着いたトーンに統一。
  • ボタン高さの完全ツライチ化:

4. カレンダーコマンドパレット整理と枠内内包化

month_schedule.php において、カレンダー部（上段または下段）に対するフィルター操作（医師絞込・種別・残数/合計表示切替）を行うコマンドパレットがカレンダー枠外に独立していたため、カレンダーを非表示（折りたたみ）にした際や上下入替を行った際に位置の不整合が発生していました。

✅
完全内包化と追従移動の達成:
コマンドパレット（.filters-compact）をカレンダー枠（#calendarWrapper）の内部ヘッダーとして配置。
これにより、カレンダーを折りたたんだ時はパレットも連動して非表示となり、上下入替（上下反転）を行った際もカレンダー本体と一緒にスムーズに下段または上段へ移動します。

5. 直近空き枠速報の右下フローティング化（Glassmorphism）

月間カレンダー画面のヘッダー部に固定されていた「直近空き枠速報（⚡）」を、当日ステータスモニターの医師通知欄スタイルを踏襲した画面右下の常時フローティングパネルへ進化させました。

🪟 ダーク系半透明グラスモフィズム

背景がわずかに透ける backdrop-filter: blur(8px) と rgba(15, 23, 42, 0.88) を採用。予約表の視認性を邪魔せず、リッチでプレミアムなデザインを実現。

✋ 自由なドラッグ移動 ＆ 24時間保持

ヘッダーバーを掴んで画面内の自由な位置へドラッグ移動可能。移動先の座標（left, top）および開閉状態は localStorage に24時間永続保持。

✕ コンパクトピル最小化

右上の✕ボタンを押すと、画面右下に小さなピルバッジ（📢 空き枠速報）として最小化。再度クリックすることでワンタッチでフルパネルに復帰。

また、ユーザーフィードバックに基づき、画面全体の強制リフレッシュタイマーは完全排除し、ヘッダー側の旧ボタン（#btnNavUrgentSlot）も撤去してフローティング側へ一本化しました。

6. modal_edit.php の本物インページモーダルダイアログ化

従来、予約登録・編集画面（modal_edit.php）は window.open() による別ウィンドウポップアップで開かれており、親画面との重なりやウィンドウ迷子、フォーカス管理が現場スタッフの課題となっていました。

🏗️ 設計上の制約と画期的な解決アプローチ

制約事項: 「呼び出し元画面（month_schedule.php 等）に modal_edit.php の巨大なコード（HTML/CSS/JS）を組み込んでしまう事は絶対に避けたい（ファイル肥大化・IDEフリーズ再発防止）。」
💡
解決アプローチ（Dynamic In-page Dialog Runner）:
呼び出し元に重いHTMLを書くのではなく、外部スクリプトが呼び出し元のDOMへ HTML5標準の <dialog> と <iframe> を必要時に動的注入するランナーアーキテクチャを採用。
親画面はスクリプトを1行読み込むだけで、一切のコード肥大化なしに本物のインページモーダル表示を実現しました。

🔄 双方向 postMessage 通信による安全な保存・自動リロード

modal_edit.php 側で予約を保存（または削除・キャンセル）した際、子ウィンドウ判定（window.opener）とインページ判定（window.parent）を自動判別： 

// modal_edit.php 側の閉じる処理
function closeModalWindow(needReload) {
    // 1. 本物インページモーダルダイアログ（iframe）からの場合
    if (window.parent && window.parent !== window) {
        window.parent.postMessage({
            type: needReload ? 'modal_edit_saved' : 'modal_edit_close'
        }, '*');
        return;
    }
    // 2. 従来の別ウィンドウからの場合（フォールバック）
    if (window.opener && !window.opener.closed) {
        if (needReload) {
            window.opener.sessionStorage.setItem('need_reload', '1');
            window.opener.location.reload();
        }
    }
    window.close();
}
