1. 改修の背景と達成ゴール

【改修の背景】
これまで小野会の各Webシステム（内視鏡予約 endoscope、勤怠管理 ono、かわらばん kawara、医師予定表 yotei など）では、カレンダー・休診日判定ロジックが各リポジトリにコピー＆ペーストされ、個別に保守されていました。
特に、勤怠システム側のAPI（/ono/api/v1/common/holidays.php）は「給与締日（前月21日〜当月20日）」固定になっていたため、月間予約カレンダーや院内掲示板のように「一般的な暦月（1日〜末日）」を扱うシステムでそのまま流用できないという根本的な課題がありました。

【本日の達成ゴール】

  • Apacheのルート直下に小野会共通APIプラットフォーム C:\Apache24\htdocspi\ を新規構築。
  • 祝日・休診日判定API（/api/v1/calendar/holidays.php）を策定し、「一般的な暦月（当月1日〜末日）」を標準としつつ、「給与締日（前月21日〜当月20日）」や任意期間にも柔軟に対応するマルチモードを実装。
  • 特大Flatpickr共通ピッカーをAPI自動取得＋インメモリキャッシュ＋オフラインフォールバック対応に強化。
  • 現行の内視鏡予約システム（endoscope）を「ラッパー方式」によって無停止・非破壊で共通API基盤へ安全に統合。
  • テストサイト（/api/index.html）および詳細技術仕様書（/api/仕様書/index.html）の配備。

小野会カレンダー判定ルールの網羅

  • 日曜休診: 曜日番号 0 は終日休診。
  • 年末年始特別休診: 12月31日 〜 1月3日 の4日間は終日休診。
  • 12月30日午後: 時間枠 13:00以降 は半休。カレンダーセルは水色ハイライト。
  • 木曜日午後: 時間枠 13:00以降 は半休。カレンダーセルは木曜水色ハイライト。
  • 国民の祝日・振替休日: 春分・秋分の天文計算、ハッピーマンデー、日曜祝日の翌日振替、5月6日特例、国民の休日（敬老の日と秋分の日が挟む平日）を完全網羅。

3. 暦月（1日〜末日）＆ 締日20日（給与月）の両対応

各システムの用途に合わせてパラメータを柔軟に切り替えられる設計としました。

リクエストURL例 返却対象期間（2026年11月例） 主たる利用システム
?year=2026&month=11
（デフォルト無指定）		 2026-11-01 〜 2026-11-30
（暦月・月末日）		 内視鏡予約、かわらばん（サイネージ）、医師予定表、一般画面
?year=2026&month=11&mode=payroll
（または &cutoff=20）		 2026-10-21 〜 2026-11-20
（小野会給与月）		 勤怠管理（ono）、給与計算、シフト作成
?start=2026-11-01&end=2026-11-15 指定された任意期間 週間ビュー、特定イベント期間、速報データ
?date=2026-11-04 指定日 1日分のみ 予約登録・更新時のリアルタイム休診チェック

4. 特大Flatpickr共通ピッカーのAPI連携化

【通信遅延ゼロのキャッシュ＆フォールバック設計】
ピッカー（onokai_flatpickr.js）は、カレンダー展開時および月めくり時に非同期（fetch）で該当月の共通APIデータを取得し、ブラウザ内メモリにキャッシュします。万が一API通信が失敗した場合でも、内蔵計算ロジックへ自動フォールバックするため、カレンダーが開かないといった障害は100%防止されます。

他システム（kawara や ono 等）でも、以下のHTMLタグを記述するだけで全く同じ特大ピッカーを1行でバインドできます：

<link rel="stylesheet" href="/api/vendor/flatpickr/flatpickr.min.css"> <link rel="stylesheet" href="/api/v1/calendar/onokai_flatpickr.css"> <input type="text" id="sampleDate" value="2026-11-04"> <script src="/api/vendor/flatpickr/flatpickr.min.js"></script> <script src="/api/vendor/flatpickr/ja.js"></script> <script src="/api/v1/calendar/onokai_flatpickr.js"></script> <script> attachOnokaiDatePicker('#sampleDate'); // ワンコールで小野会角丸ピル特大ピッカーに変換！ </script>

5. 内視鏡システム（endoscope）の安全なラッパー移行

【危険性低減・無停止移行の徹底】
内視鏡システム内の20以上のPHPファイル（slot_search.php, month_schedule.php 等）を直接書き換えるのではなく、既存の calendar_helper_onokai.php を共通基盤 /api/v1/calendar/helper.php への透過的ラッパーとして再構築しました。

これにより、内視鏡側の全画面・APIは1文字も修正することなく、背後で共通APIの最新コアロジックを直接実行する状態へ移行しました。

// c:\Apache24\htdocs\endoscope\calendar_helper_onokai.php $common_helper_path = dirname(__DIR__) . '/api/v1/calendar/helper.php'; if (file_exists($common_helper_path)) { require_once $common_helper_path; } else { // 共通API未配置時の安全フォールバック定義 }
