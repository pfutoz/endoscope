2. action_schedule.php 予約保存バインドエラー完全修復

2.1 不具合の症状とエラー内容

modal_edit.php から新規予約を保存しようとした際、以下の PDO 例外が発生し、保存に失敗する事象が発生していました。

エラーメッセージ:
保存失敗: クエリ実行エラー: SQLSTATE[08P01]: <<Unknown error>>: 7 ERROR: バインドメッセージは17パラメータを提供しましたが、準備された文"pdo_stmt_00000003"では18必要でした

2.2 原因の特定（10月2日改修時のデグレード）

2026年10月2日夕方に実施された「病棟管理システム・電子食事箋連携」に伴う改修において、SQL 文には新設カラム is_admission のプレースホルダー（:is_admission）が追加されて計18個となっていたのに対し、PDO 実行時に渡すバインド配列 $params に ':is_admission' => $has_admission_param の代入行が記述漏れとなっていた（17個のまま）ことが原因でした。

2.3 実施した修正内容

INSERT 処理へのパラメータ追加に加え、既存予約の更新（UPDATE）処理側にも is_admission の更新・差分検知・レスポンス連動を網羅しました。 

// action_schedule.php (抜粋)

// 1. 新規登録 (insert) パラメータ配列への追加 (18個完全一致)
$params = [

if (!$is_diff) {

3. modal_edit.php 病棟連動（入院予定）初登録前リアルタイム制御

3.1 現場の要件

初登録前（空枠からの新規予約登録時など）の入力段階において、検査種別の選択状態に応じて「病棟管理システム連動用: [ 入院予定 ]」パネルが即座に表示・連動し、スタッフが意識的に確認・判断できるUIが求められました。

選択された検査種別 パネル表示制御 入院予定チェックボックス状態
TCF / W 即表示（パネルを展開） 通常は手動チェック可能。
備考に「ポリペクあり」「入院可」があれば自動サジェストON。
ポリペク 即表示（パネルを展開） 自動で即座に ON
（「入院予定 (ポリペク確定)」「💡 ポリペク確定」バッジ表示）
上記以外
(GIF, 浣腸CF, エコー, 未選択等)		 非表示化（display: none） 自動で即座に OFF（誤登録防止）

3.2 実装された UI モックアップ（再現）

🏥 病棟管理システム連動用: 💡 ポリペク確定
※ 検査種別が W / TCF の時は必要に応じてチェック、ポリペク時は自動で入院確定となります。
※ 厨房の週間食事予測（朝・昼・夕）へ即座に反映されます。

3.3 実装コード（JavaScript）

検査種別変更時に呼び出される updateFormFieldsByExamType 内に即時連動ロジックを統合し、さらに Quill エディタ（備考欄）の text-change イベントにもサジェスト判定を多重連動させました。 

// modal_edit.php 内の updateFormFieldsByExamType より抜粋
const panelWard = document.getElementById('panelWardIntegration');
const isPolypep = (etype === 'ポリペク' || etype.includes('ポリペク'));
const isWOrTcf = (etype === 'TCF' || etype === 'W');

if (panelWard) {
    if (isPolypep) {
        // ・ポリペク⇒即表示、さらに入院予定ON
        panelWard.style.display = '';
        window.userModifiedAdmission = false; // ポリペク自動確定を最優先
        updateAdmissionUI(true, 'ポリペク確定');
    } else if (isWOrTcf) {
        // ・TCF/W選択⇒即表示
        panelWard.style.display = '';
        if (isUserChange) {
            let remText = (typeof quill !== 'undefined' && quill) ? quill.getText() : '';
            checkAdmissionSuggestion(remText);
        }
    } else {
        // ・検査種別が上記以外が選択されたら入院予定OFF/非表示化
        panelWard.style.display = 'none';
        window.userModifiedAdmission = false;
        updateAdmissionUI(false, '');
    }
}
