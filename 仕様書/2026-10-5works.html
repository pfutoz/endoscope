1. 改修の背景と解決課題

【不具合事象】 空き枠検索画面（slot_search.php）の「⚡直近空き枠速報」タブおよびカレンダー画面等の右下に常駐する速報モーダル（urgent_slot_modal_inc.php）において、祝日（例: 2026年10月12日 月曜日・スポーツの日）に月曜日の曜日定員（誠吾先生 残7枠、義智先生 残7枠 等）がそのまま参照され、休診日であるにもかかわらず空き枠候補カードとして表示されてしまう不具合が発生していました。

調査の結果、直近速報API（action_slot_assistant.php）内の日付走査ループにおいて if ($dow === 0) continue; と日曜日のみを除外判定しており、小野会専用カレンダーヘルパー（calendar_helper_onokai.php）による祝日・振替休日・医院特別休診（年末年始等）の判定が呼び出されていないことが原因と特定しました。

さらに、ユーザーとの対話型仕様確認（/grill-me）に基づき、「休診日は原則候補から除外するが、祝日・休診日であっても管理者が出勤例外（m2_doctor_attendance）で明示的に枠を設定した場合は出勤例外最優先ルールにより候補対象とする」という医院の運用実態に完全合致した仕様を策定・実装しました。

2. 休診判定と出勤例外最優先ロジック

今回の改修では、システム全体の枠管理ルール（出勤例外 > 日別上書き > 曜日パターン）を厳格に順守し、以下の多層判定アルゴリズムを構築しました。

判定フェーズ 処理内容 結果 / 挙動
① 出勤例外プリフェッチ 検索対象期間（本日〜30日後）の m2_doctor_attendance を一括取得しメモリマップ化。 DBクエリを1回に集約し高速化。休診日に枠が設定されている医師を即時判定可能。
② 小野会カレンダー判定 check_onokai_calendar($cur_date, null) を実行。日曜日、日本の祝日、振替休日、年末年始休診（12/31〜1/3）を判定。 休診日フラグ（$is_closed）を取得。
③ 休診日の大枠スキップ 休診日の場合、その日に出勤例外による大腸枠（TCF > 0）が1件も存在しなければ、日付走査を即時スキップ。 出勤例外のない祝日（2026-10-12等）は完全に除外され、無駄な枠計算・SQL発行もゼロに。
④ 医師別・科別の厳格フィルタ 休診日に出勤例外がある場合、出勤例外が登録されている医師のみを候補対象とし、科定員も出勤例外枠のみで再計算。 休診日に特定の医師だけ臨時診療する場合、出勤例外のない他医師の通常曜日パターン枠が混入するのを100%防止。

// ★ 小野会専用カレンダーによる休診（日曜・祝日・振替休日・年末年始休診など）の判定
$day_check = check_onokai_calendar($cur_date, null);
$is_closed = (bool)($day_check['is_closed'] ?? false);

if ($is_closed) {
    // 休診日だが「出勤例外」で大腸枠（TCF>0）が登録されている医師がいるかチェック
    $has_tcf_exception_on_closed = false;
    if (!empty($attendance_map[$cur_date])) {
        foreach ($attendance_map[$cur_date] as $dep_code => $doc_exceptions) {
            foreach ($doc_exceptions as $doc_name => $slot_info) {
                if ($slot_info['tcf'] > 0) {
                    $has_tcf_exception_on_closed = true;
                    break 2;
                }
            }
        }
    }
    // 出勤例外による大腸枠が設定されていない休診日はスキップ
    if (!$has_tcf_exception_on_closed) {
        continue;
    }
}

7. 空き枠速報カード「カレンダー表示」遷移先の適正化（open_new除去）

【改修の背景・課題】

空き枠検索画面（slot_search.php）の直近速報カードおよび各画面の速報モーダル（urgent_slot_modal_inc.php）には、以下の2つのボタンが配置されています：

  • 「📅 カレンダー表示」: 該当日のカレンダー・予約一覧を選択状態で開き、状況を確認するボタン。予約するかどうかはユーザーの判断に委ねられる。
  • 「➕ この枠で予約」: 該当科・該当日のカレンダーを開くと同時に、新規予約入力モーダルを自動起動するボタン（open_new=1 連動）。

しかし、action_slot_assistant.php で返却される jump_url（カレンダー表示リンク）の末尾に誤って &open_new=1 が付与されていたため、「カレンダー表示」をクリックした際にも「この枠で予約」と全く同じように新規予約モーダルが自動起動してしまう事象が発生していました。

改修仕様と差分内容

action_slot_assistant.php の jump_url 生成部から &open_new=1 を除去し、純粋に指定日付が選択された状態で月間カレンダーを開くよう修正しました。
