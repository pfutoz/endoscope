1 本番サーバーのhtdocsが「T:ドライブ」として常時共有マウントされていること

本システムは、差分スキャン・事前バックアップ・ファイル配布を行う際、本番環境のファイルを T:\<system> として直接比較・コピーします。

本番サーバーIP: 192.168.1.16
本番共有パス: \\192.168.1.16\c$\Apache24\htdocs または \\192.168.1.16\htdocs
割り当てドライブ文字: T:
※Windowsエクスプローラーの「ネットワークドライブの割り当て」で、「サインイン時に再接続する」 に必ずチェックを入れて資格情報を保存してください。
2 なぜ Apache (PHP) ではなく Node.js 支援サーバー (ポート5050) が必要なのか？

ローカルの Apache は Windows の NT AUTHORITY\SYSTEM（システム特殊アカウント） でサービス稼働しています。

⚠️ SYSTEMアカウントの制約:
Windowsのセキュリティ仕様により、SYSTEMアカウントはネットワーク共有（T:ドライブや UNCパス \\192.168.1.16）へのアクセス権限が拒否（ブロック）されます。

そのため、Windowsにログインしている 一般ユーザー（Owner）権限 で動作する専用の Node.js 支援サーバー（ポート5050）を常駐させ、本番サーバーとの安全な通信・比較・デプロイを実現しています。

3 全自動の事前バックアップ退避仕様

本番配布が実行されると、上書き対象となる本番既存ファイルはコピー前に自動的に c:\deploy_backups\<system>\ 配下へ日時付きZIP（例: endoscope_backup_20261002_120000.zip）として丸ごと保存されます。
万が一の不具合時は、画面の「🕒 過去バックアップ ＆ ロールバック」タブからワンクリックで元の状態へ即座に復元可能です。

💻 PC交換・OS再インストール時の復旧手順（完全3ステップ）

  1. Node.js のインストール: Node.js 公式サイト（nodejs.org）から LTS 版をインストールします（外部パッケージの追加インストールは一切不要です）。
  2. T:ドライブの割り当て: エクスプローラーの「PC」右クリック ➔「ネットワークドライブの割り当て」で、ドライブを T:、フォルダーを \\192.168.1.16\c$\Apache24\htdocs（または \\192.168.1.16\htdocs）に設定し、「サインイン時に再接続する」にチェックを入れて完了します。
  3. 自動常駐の登録: フォルダ内の register_startup.bat をダブルクリックして実行します。これでWindows起動時に自動でサーバーが常駐します。

❓ よくある症状と対処法

症状1: 「システム一覧の取得に失敗しました: Failed to fetch」と表示される
原因: Node.js 支援サーバー（ポート5050）が起動していません。
対処法: c:\Apache24\htdocs\deploy_manager\start_deploy_manager.bat をダブルクリックして起動するか、register_startup.bat を実行してWindows起動時自動常駐を設定してください。
症状2: 「⚠️ 本番サーバー (192.168.1.16) 未接続」と表示される
原因: 本番サーバー（192.168.1.16）の電源が落ちているか、ネットワーク接続が切断されているか、または T: ドライブのマウントが外れています。
対処法: エクスプローラーを開き、「T:」ドライブをダブルクリックして開けるか確認してください。パスワードを求められた場合は入力して「資格情報を記憶する」にチェックを入れてください。
付属する管理バッチファイルの使い方
  • start_deploy_manager.bat : サーバーを起動しブラウザを開く通常起動スクリプト
  • register_startup.bat : Windowsスタートアップに登録し、PC起動時に自動常駐させるスクリプト
  • unregister_startup.bat : 自動常駐を解除するスクリプト
  • diagnostics.bat : コマンドプロンプト上で各接続要件を一発診断するスクリプト
