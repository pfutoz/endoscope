# 院内本番サーバー ヘルス＆SMART監視エージェント (Server Health Monitor)

本ツールは、院内本番Webサーバー（`192.168.1.16`）のハードウェア健全性（SSD/HDDのSMART情報、空き容量、CPU・メモリ負荷、OS稼働時間、Apache稼働状態）を自動収集し、**院内システム総合デプロイマネージャー (Deploy Manager)** から一目で確認できるようにする仕組みです。

---

## 仕組み・構成概要

1. **定期自動収集 (サーバー側)**:
   - `collect_server_health.ps1` が10分毎にWindowsタスクスケジューラ（SYSTEM特権）によって自動実行されます。
   - 収集結果は `c:\Apache24\htdocs\_server_health.json` にUTF-8で保存されます。
2. **オンデマンド取得 (HTTPフォールバック)**:
   - `server_health_api.php` により、ブラウザやDeploy Managerから直接HTTP経由で最新ヘルス情報を取得・自動リフレッシュも可能です。
3. **Deploy Managerでのリアルタイム表示 (クライアント側)**:
   - Deploy Manager起動時および「最新状態を再診断」クリック時に、Webサーバーへの即時Ping（応答時間ms）と、サーバーのSMART・ストレージ・リソース情報を統合して画面にグラフィカルに表示します。

---

## 収集・監視項目

| 項目 | 内容 | 警告・注意基準 |
| :--- | :--- | :--- |
| **ストレージ SMART** | 物理ディスク（SSD/HDD）の健全性、故障予兆フラグ、SSD残存寿命(%)、温度(℃)、エラー数 | `PredictFailure` が True、またはSSD残存寿命 ≤ 10% |
| **ディスク空き容量** | C: ドライブ等の使用量、空き容量(GB)、使用率(%) | 使用率 ≥ 85% または 空き容量 < 25GB で注意、≥ 95% で危険 |
| **Webサーバー** | Apache2.4 サービス稼働状態、ポート80待機、即時HTTP応答時間(ms) | サービス停止 または HTTP 5xx/タイムアウト |
| **システムリソース** | メモリ使用量(GB)/使用率(%)、CPU使用率(%) | メモリ使用率 ≥ 80% で注意、≥ 90% で危険 |
| **稼働状況** | コンピュータ名、OSバージョン、OS連続稼働時間(Uptime)、最終再起動日時 | データ更新が30分以上途絶えた場合に警告 |

---

## 本番サーバー側でのタスク常駐手順（初回のみ）

本フォルダを本番サーバー（`c:\Apache24\htdocs\deploy_manager\server_agent\`）に配置後、以下の手順でタスクスケジューラに登録します。

1. 本番サーバーPC（`192.168.1.16`）にサインインします。
2. エクスプローラーで `c:\Apache24\htdocs\deploy_manager\server_agent\` を開きます。
3. **`register_server_health_task.bat`** を右クリックし、**「管理者として実行」** をクリックします。
4. 「タスクの登録に成功しました」と表示されたら完了です。以後はPC起動中、10分毎にバックグラウンドで自動更新されます。

※ タスクを停止・解除したい場合は、**`unregister_server_health_task.bat`** を管理者として実行してください。
