======================================================================
  医療法人小野会 クライアント端末用 ヘルス＆SMART自動監視エージェント
======================================================================

本ツールは、院内の重要端末（受付PC、診察室Dr端末、外注検査端末、院内検査端末など）
のハードウェア健全性（SSD/HDD寿命、Cドライブ空き容量、CPU・メモリ、稼働時間）を
【10分毎】に自動収集し、本番サーバー（/ip/ 端末台帳管理表）へ送信する仕組みです。

----------------------------------------------------------------------
【かんたん導入手順（初回のみ）】
----------------------------------------------------------------------
1. ダウンロードした ZIP ファイルを任意の場所（例: C:\tools\onokai_agent や デスクトップ等）
   に「すべて展開」してください。

2. 展開されたフォルダ内にある
   「register_client_health_task.bat」を右クリックし、
   【管理者として実行】をクリックしてください。

3. 画面に「【設定完了】」と表示されたら導入完了です！
   以後はPC起動中、10分毎にバックグラウンド（画面非表示・SYSTEM特権）で
   本番サーバー（192.168.1.16/ip/）へ最新ヘルス情報が自動送信されます。

----------------------------------------------------------------------
【同梱ファイル一覧】
----------------------------------------------------------------------
- register_client_health_task.bat   : 定期監視タスク登録バッチ（管理者として実行）
- unregister_client_health_task.bat : 定期監視タスク解除バッチ
- test_send_once.bat                : 接続・送信の単体動作確認バッチ
- collect_client_health.ps1         : ヘルス情報収集・HTTP送信PowerShellスクリプト
- register_client_task.ps1          : タスクスケジューラ登録処理本体
- unregister_client_task.ps1        : タスク解除処理本体
- README_CLIENT_HEALTH.txt          : 本説明書
