01

システム全体概要・アーキテクチャ

システム基盤 二重DB連携

本システムは、確定カルテ情報を管理する電子カルテ（MALL3 / SQL Server）と、院内現場での超高速な枠調整・動線管理を担う予約DB（PostgreSQL 18.3）を安全にハイブリッド連携させています。

データベース / サーバー アクセス方式 役割・取り扱うデータ
電子カルテ MALL3
SQL Server (192.168.1.77)		 読み取り専用 (SELECT) 患者基本情報（カルテID、氏名、カナ、生年月日、性別、保険情報）、カルテ診療記事メモ（本日メモ・カルテメモ・患者メモ）。
内視鏡予約・進捗DB
PostgreSQL 18.3 (localhost / 192.168.1.16)		 完全読み書き (R/W) 内視鏡予約台帳 (`t_endoscopy_schedule`)、当日進捗ステータス (`t_progress_status`)、前処置室ベッド割当、定型文マスタ、操作監査ログ。

💡 電子カルテMALL3のデータ保護と高速化

電子カルテMALL3のマスターテーブルは直接書き換えません。現場ナースや医師が行う「枠仮押さえ」「前処置室ベッド番号の割り当て」「当日進捗ステータス（来院〜処置〜検査〜リカバリ）」はPostgreSQL側で独立して即座に更新されるため、電子カルテ端末が重くならず超高速（10ms以内）に応答します。

UIパーツ・項目 配置場所 / 識別 詳細仕様 ＆ 現場での操作方法
自動更新ピル ヘッダー右上 `[5分] [10分] [15分]` バックエンドPostgreSQLの最新予約データを指定間隔で自動リロード。診察室や受付での他端末同時変更を自動反映（デフォルト5分）。
診療科切替 ツールバー左端 `[● 肛] [● 胃]` シアン色（肛門科）と薄グレー（胃腸科）で表示データを瞬時にフィルタリング。選択中の科に応じて時間枠定義や医師が切り替わります。
枠フィルターカプセル ツールバー中央 `枠: [GIF] [エコー] [TCF] [迷子]` 【2026-09-29改修】チェックボックスを廃止し、高さ24pxツライチのカプセル型トグルボタンに統一。エコー枠はエコー専用水色（#0284c7 / 表示「US」）に連動。
オプショントグル群 ツールバー右側
  • 伏字: カウンター等で患者に見せる際、氏名を非表示化して個人情報を保護。
  • 起動時: 画面を開いた際、自動的に本日日付行へスムーズスクロール。
  • 迷子: 時間枠不整合や配置不正データを検知してオレンジ警告表示。
  • 削除: 選択セルの削除トリガーを有効化。
  • 未割当: 担当医や時間枠が未確定のキープデータを抽出。
表示切替 ツールバー右端 `[使用/最大] [残数]` 予約枠の表示を「予約件数 / 最大受入可能数」形式か、あと何人受入可能かの「残枠数」形式かにワンクリックで切り替え。
予約カードセル マトリクス各セル 上段にカルテIDと年齢バッジ、中段に患者氏名、下段に生年月日と検査種別バッジ（[TCF]、[GIF]、大腸＋胃同日時は[W]）を表示。
※予約可セル オレンジ色背景セル 枠だけ仮確保（キープ）された状態。未確定枠が一目で視認でき、ダブルブッキングを防止。
休診日行 赤色背景セル 日曜日・小野会休日ルール適用日は赤色帯で表示され、誤登録を防止。

⚠️ マトリクス画面でのマウス操作ルール（誤操作防止）

  • 新規登録：セルの何もない空白部分（※枠なし等）をクリックすると新規予約入力モーダルが開きます。
  • 修正・削除：既存予約を変更する場合は、枠内の患者名部分をクリックしてください（カーソルが指マーク ☝ に変わります）。
  • ドラッグ移動：予約枠を別の日時へ移動させる場合は、名前以外の余白部分をクリックしてドラッグしてください（カーソルが手袋マーク ✋ に変わります）。

4.1

画面各ボタン・UIコンポーネント完全機能リファレンス

月間カレンダービュー（month_schedule.php）は、当院の予約管理において最も高頻度で使用されるメイン画面です。画面内に配置された全てのボタン・トグル・UIパーツの配置場所と詳細機能を網羅しています。

UIカテゴリ ボタン・コンポーネント名 外観・配置場所 機能詳細 ＆ 現場での活用ルール
① ヘッダー操作
ナビゲーション 		診療科切替 ヘッダー左 [肛門科] [胃腸科] 診療科ごとの独立した予約マスター・カレンダー・医師設定へ切り替えます。選択中の診療科がエメラルドグリーン（胃腸科）またはネイビー（肛門科）で点灯します。
当日ホワイトボード ヘッダー右 当日ホワイトボード progress_monitor.php を別タブで展開。当日のリアルタイムな検査実施状況・呼出状態・前処置室・リカバリー室滞在状況を大画面電子ホワイトボードとして表示します。
ノート表示 ヘッダー右 ノート表示 schedule_note.php（紙バインダー風・超高速モード）へ遷移。月間カレンダー計算を省き、30ms未満の応答速度で当日の予約者を全幅一覧・キーボード操作できます。
予約マトリクス ヘッダー右 予約マトリクス month_schedule_v2.php（縦型2次元マトリクス）へ遷移。縦軸＝日付、横軸＝各医師・検査室のグリッドで、月間の空き枠の偏りや過密状況を一目で鳥瞰できます。
空き枠検索 ヘッダー右 空き枠検索 slot_search.php / custom_slot_search.php へ移動。「火曜・午前中・誠吾先生」など患者の希望条件に合致する直近の最短空き枠を高速一発検索します。
重複チェック ヘッダー右 重複チェック モーダルダイアログで起動。同一カルテIDで未来の日程に複数の予約が入っている二重予約・過剰予約を自動検出し、誤登録やキャンセルの放置を防止します。
操作履歴 (Undo) ヘッダー右 操作履歴 action_audit_log.php モーダルを起動。自端末および院内で行われた直近の予約登録・変更・削除ログを表示し、誤操作をワンクリックで元の状態に即時Undo復元できます。
アラートスキャン ヘッダー右 アラートスキャン 当日および指定日の受診者全員の「抗血栓薬・アレルギー・感染症・発熱風邪」等のリスクを院内カルテから一括走査し、赤帯アラートで安全確認を行います。
カレンダーを折りたたむ ヘッダー右白ボタン カレンダーを折りたたむ 上部の月間カレンダーグリッドを非表示にトグル切り替えし、下部の予約一覧テーブルを作業画面いっぱいに広く表示します（ノートPC等での作業効率向上）。
上下入替 ヘッダー右白ボタン 上下入替 月間カレンダーと下部予約一覧テーブルの配置順を上下反転させます。好みのレイアウトに即座に変更できます。
② カレンダー
コマンドパレット
(内包バー) 		医師絞込フィルター [全医師] [哲也 0] [義智 5]... 各ボタンに当月の担当予約件数がバッジ表示されます。特定の医師ボタンを押すと、カレンダー内の数値がその医師の担当枠のみに瞬時に絞り込まれます。
種別絞込フィルター [全種別] [🔵 GIF] [🟠 エコー] [🟢 TCF] 胃カメラ（GIF）、腹部エコー、大腸カメラ（TCF）ごとに表示をフィルタリングします。「大腸カメラの空きだけを見たい」場合にワンクリックで絞り込めます。
表示モード切替 [📊 使用/最大] [📉 残数] [🔢 検査数] カレンダー各セル内の数値表示を切り替えます。
・使用/最大: 例 5/6（予約数/定員枠）
・残数: 例 残 1（空きスロット数。満枠は赤背景）
・検査数: 確定した検査の純粋な件数のみを表示
③ 月ナビゲーション
＆ジャンプ 		月送り / 今日ボタン [◀] [📅 今日] [▶] カレンダーの表示月を前月・次月へ送ります。「📅 今日」を押すと、何ヶ月先に移動していても一発で本日の月・選択日に復帰します。
クイック月ジャンプピル 右側 [10月] [11月] [12月] ['27/1] 直近数ヶ月先および年またぎ（'27/1等）の月へ1クリックで直行できるタブ群です。先々の定期フォローアップ予約を取る際に高速ジャンプできます。
④ カレンダーセル

よくある質問 ＆ トラブルシューティング

Q & A
Q1

マトリクスで文字が赤くなっている、または「迷子」の警告が出る

A: 予約の予定時刻とマトリクスのコマ枠時間が不整合を起こしています。予約修正画面を開き、「時間枠」を選び直して再保存してください。

Q2

カルテ（MALL3）で書いた最新メモが予約画面に出ない

A: 予約ダイアログ右上の「🔄 メモ再読み込み」を押してください。SQL Serverから最新の診療記事メモを即座に再取得します。

Q3

画面が動かなくなった / 接続エラーが表示される

A: キーボードの [F5] または [Ctrl + F5]（強制再読み込み）を押してください。改善しない場合はLANケーブルやネットワーク接続をご確認ください。
